# How-to guides

Task-shaped recipes for people who already know what they want to do. If you are
new to the library, start with
[Build your first model](../tutorials/first-model.md) instead.

- [How to run a simulation](run-a-simulation.md) — hand a model to
  `@idfkit/engine` and read the results.
- [How to parse in the browser](parse-in-the-browser.md) — serve the schema
  bundle and keep the parse synchronous.
- [How to collect diagnostics instead of throwing](collect-diagnostics.md) —
  what an editor or a batch job needs.
- [How to edit extensible groups](edit-extensible-groups.md) — vertices, branch
  lists, and anything else that repeats.
- [How to handle a version you do not know ahead of time](handle-unknown-versions.md)
  — open whatever file you are given.
- [How to compare two EnergyPlus versions](compare-versions.md) — what changed
  between releases, cheaply.

For the API itself, see [Reference](../reference/index.md).
